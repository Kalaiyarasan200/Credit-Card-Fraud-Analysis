💳 Credit Card Fraud & Transaction Analytics

An end-to-end Data Analytics project using MySQL and Tableau Public to analyze credit card transactions, identify fraudulent patterns, evaluate transaction risk factors, and create interactive dashboards for data-driven insights.

📌 Project Overview

Credit card fraud is a major challenge for financial institutions. This project analyzes transaction-level data to identify patterns associated with fraudulent transactions.

The project follows a complete analytics workflow:

Kaggle Dataset
      ↓
MySQL Data Import
      ↓
Data Cleaning
      ↓
Feature Engineering
      ↓
SQL Exploratory Analysis
      ↓
CSV Export
      ↓
Tableau Public
      ↓
Interactive Dashboards

🎯 Project Objectives

1.Analyze overall credit card transaction activity.

2.Identify fraudulent and legitimate transactions.

3.Calculate fraud rate and fraud amount.

4.Identify high-risk merchant categories.

5.Analyze fraud patterns by transaction time and amount.

6.Study fraud across different age groups.

7.Analyze foreign vs domestic transactions.

8.Identify the impact of location mismatches.

9.Analyze device trust and transaction velocity.

10.Identify high-value fraudulent transactions.

11.Build interactive Tableau dashboards for fraud monitoring.

🛠️ Tools & Technologies

1.MySQL - Data cleaning, transformation and analysis.

2.SQL - EDA, aggregation and feature engineering.

3.Tableau Public - Interactive visualization and dashboards.

4.Microsoft Excel - CSV	Data storage and exchange.

5.GitHub - Project documentation and version control.

📊 Project Outcome

This project demonstrates an end-to-end Data Analyst workflow, starting from raw transaction data and progressing through SQL-based data cleaning, feature engineering, exploratory analysis, and interactive Tableau visualization.

The final dashboards provide an easy-to-understand view of fraud trends, transaction behavior, risk factors, and high-value fraudulent transactions.
